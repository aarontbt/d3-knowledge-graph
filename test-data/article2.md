# Machine Learning Basics

Machine learning enables computers to learn from experience without being explicitly programmed.

## Types of Machine Learning

### Supervised Learning
- Classification
- Regression

### Unsupervised Learning
- Clustering
- Dimensionality reduction

### Reinforcement Learning
- Agent-based learning
- Reward optimization

## Popular Algorithms

- Linear Regression
- Decision Trees
- Random Forests
- Support Vector Machines
- Neural Networks

Machine learning forms the foundation of [[Deep Learning]] and is implemented using [[Python]] and frameworks like [[TensorFlow]].
